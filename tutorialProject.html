The Tutorial Project
The SCP: SL Tutorial Project

The SCP:SL Tutorial Project is a community made pack of playable tutorials
that new and long time players can use to learn how to play the game / touch up on their skills.

Tutorial Packs

Tutorial packs are a way that we group the tutorials together, Tutorials 1-3 being in pack 1.
This was done to allow players to be able to play through each tutorial
in which ever order they would like in each pack.
Players must complete all the tutorials in each pack in order to unlock the next pack.
